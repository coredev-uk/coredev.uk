Scope: a Meridian mockup of the coredev.uk homepage (Experience) and the homelab write-up (Read), built beside the live site for comparison. The live navy site stays as it is.

Audience and job: as PRODUCT.md. A visitor should come away with an accurate picture of who Paul is, what he has built, and how to reach him.

Constraints: the copy is the live site's, with microcopy edits only and no new claims. The palette, family, radii and motion follow Meridian (`~/.dotfiles/lib/theme/default.nix`, `home/common/programs/quickshell/DESIGN.md`).

## Direction contract

seed: none (direction pinned by the user: their Meridian system theme)

THESIS: the site keeps time like the desktop it was built on. It refuses the split-hero portfolio: the first viewport is set like the shell's lock screen, with a live day at Greenwich running under the name.

OWN-WORLD: night-slate grounds stepped ground → plate → inset, with every edge a 1px rule. Enamel legends. Gilt only for "here" (the current page, the now-dot, the current section) and "on" (active projects), plus one primary button. Atkinson Hyperlegible Next with tabular figures, and Fira Code for code only. Corners step 10/8/6/2. Screenshots are windows, so they get the Float shadow; anchored plates stay flat.

STORY: a name, a role and a live day, then the work as windows, the full record as rows, and the way to reach him.

FIRST VIEWPORT: the instrument bar (pages as workspace numerals, a clock group with a mini arc). The name in Light at display scale, top-left, with the lead and a gilt primary button below it. The Cider window floats on the right. A full-measure day arc forms the hero's horizon, with sunrise, sunset, now and today's pushes marked, and the latest push line beneath it.

FORM: the Meridian Window register for the hero, and the Instrument register for everything else.

SIGNATURE: the day arc, computed in the browser for Greenwich, with GitHub pushes ticked on it. On the write-up, the contents rail uses the workspace index: the current section is gilt, with a rule that glides between sections.
