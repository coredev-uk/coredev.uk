# Cider Music Player

A revolutionary cross-platform Apple Music experience that redefined how users interact with their music library. As a core contributor to the Cider project, I played a crucial role in developing both the backend infrastructure and frontend functionality for this popular music application.

## Project Overview

Cider was built from the ground up with performance in mind, serving over 13,000+ users worldwide. The application provided a modern, customizable alternative to iTunes with native backends for each operating system, ensuring minimal overhead and maximum performance.
